Set up the adapter (once)

A browser can only use a USB device that has Microsoft's generic WinUSB driver. Windows gives the T3U/T4U its Wi-Fi driver, so swap it once with Zadig:

  1. Plug in the T3U/T4U and download Zadig.
  2. Run it and turn on Options → List All Devices.
  3. Pick 802.11ac NIC from the list. Check the USB ID: 2357 012D for T3U or 2357 0115 for T4U.
  4. Choose WinUSB as the target driver and click Replace Driver (or Install Driver).
  5. Come back here and click Connect. Close other programs that use the adapter first.

After this the adapter no longer works as a normal Wi-Fi adapter on this PC. To undo it, open Device Manager, uninstall the device (with its driver) and replug it. OpenIPC's adapter notes show the same Zadig steps for other Realtek adapters.

Linux

Keep the kernel driver off the card and let your user open it: sudo modprobe -r rtw88_8822bu (or blacklist rtw88_8822bu), and a udev rule such as SUBSYSTEM=="usb", ATTR{idVendor}=="2357", ATTR{idProduct}=="012d", MODE="0660", TAG+="uaccess".
